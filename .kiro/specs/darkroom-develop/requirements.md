# Requirements: Develop a photo in the tray
1. WHEN the user drops an image, THE SYSTEM SHALL show it as blank paper in the tray.
2. WHILE developing, THE SYSTEM SHALL reveal the image progressively over a user-chosen time (5-60 s).
3. THE SYSTEM SHALL let the user pull the print early (stop bath), keeping the current exposure.
4. IF prefers-reduced-motion is set, THEN THE SYSTEM SHALL show the final image with a short fade.
5. THE SYSTEM SHALL never send image data over the network.
