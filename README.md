# Cuarto Oscuro — the darkroom, resurrected

**Kiroween 2026 · Category: Resurrection**

Digital photography killed the darkroom ritual: red safelight, enlarger, trays,
the print slowly appearing in the developer. *Cuarto Oscuro* brings it back in the
browser: load a negative, set the exposure, dodge and burn by hand, then watch
the print develop in the tray — shadows first — before fixing it.

## Run
Open `src/index.html` in a browser. One file, no build, no server:
your photos never leave your machine.

## Features
- Load your own negative or use the default one (*Dracula*, from the ORCHIDACEAE series)
- Exposure timer, paper grade (contrast), dodge & burn with the mouse
- Developing tray: the image appears shadows-first, like real paper
- Fixer, toning, adjustable grain, safelight on/off, darkroom sounds
- Export the finished print as an image
